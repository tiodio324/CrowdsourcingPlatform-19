# Обзор проекта: Платформа для коллективного обсуждения идей

## 📋 Описание проекта

Данное веб-приложение представляет собой краудсорсинговую платформу для сбора, обсуждения и голосования за идеи. Система разработана как Single Page Application (SPA) без использования `react-router`, что обеспечивает быструю навигацию между разделами без перезагрузки страницы.

**Основная цель проекта**: Создание платформы для коллективного обсуждения идей, где пользователи могут предлагать свои идеи, голосовать за понравившиеся и отслеживать рейтинг лучших предложений.

## 🎯 Основные возможности системы

### Для всех пользователей (включая неавторизованных):

1. **Просмотр идей**
   - Фильтрация по категориям
   - Поиск по названию и описанию
   - Сортировка по рейтингу и дате

2. **Просмотр рейтинга**
   - Топ лучших идей
   - Статистика голосования

3. **Просмотр категорий**
   - Список всех категорий
   - Количество идей в категории

### Для авторизованных пользователей (Участник):

1. **Создание идей**
   - Добавление новых идей
   - Выбор категории
   - Описание и обоснование

2. **Голосование**
   - Голосование за/против идей
   - Изменение своего голоса

3. **Комментирование**
   - Добавление комментариев к идеям
   - Обсуждение с другими участниками

### Для администраторов:

Все функции участника, плюс:

1. **Модерация идей** (CRUD операции)
   - Одобрение/отклонение идей
   - Редактирование и удаление
   - Изменение статуса

2. **Управление категориями** (CRUD операции)
   - Создание и редактирование категорий
   - Деактивация категорий

3. **Управление комментариями**
   - Модерация комментариев
   - Удаление неуместных

## 🔐 Система ролей и прав доступа

### Роли пользователей:

1. **viewer** (Наблюдатель) - роль по умолчанию
   - Просмотр идей, категорий, рейтинга
   - Нет возможности голосования и комментирования

2. **contributor** (Участник) - требует авторизацию
   - Все права наблюдателя
   - Создание идей
   - Голосование и комментирование

3. **admin** (Администратор) - требует авторизацию
   - Все права участника
   - Модерация идей и комментариев
   - Управление категориями (CRUD)
   - Доступ к разделу "Администрирование"

**Пароли для входа** находятся в файле `CREDENTIALS.md`

## 🗄 Структура данных

### Основные сущности:

1. **Idea (Идея)**
   - id, title, description
   - categoryId, authorId
   - status (pending/approved/rejected)
   - votesUp, votesDown
   - createdAt, isActive

2. **Category (Категория)**
   - id, name, description
   - color, sortOrder
   - isActive

3. **Comment (Комментарий)**
   - id, ideaId, authorId
   - content, createdAt
   - isActive

4. **Vote (Голос)**
   - id, ideaId, oderId
   - type (up/down)
   - createdAt

## 📚 Что желательно понимать для защиты диплома

### Теоретическая часть:

1. **Что такое краудсорсинг?**
   - Crowdsourcing - привлечение широкого круга людей для решения задач
   - Использование коллективного интеллекта

2. **Система голосования**
   - Upvote/Downvote механика
   - Расчет рейтинга идей

3. **SPA (Single Page Application)**
   - Приложение загружается один раз
   - Навигация через MobX store

4. **Firebase Realtime Database**
   - Облачная NoSQL база данных
   - Синхронизация в реальном времени

### Возможные вопросы:

1. **"Как предотвращается накрутка голосов?"**
   - Один пользователь - один голос за идею
   - Авторизация обязательна для голосования

2. **"Как работает модерация?"**
   - Новые идеи проходят модерацию
   - Администратор одобряет/отклоняет
